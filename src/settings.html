OpenAI API Key

Used for gpt-4o-mini classification — stays on your device

Not set

Get your key at platform.openai.com.

What it costs: every inbox email in your sync window is sent to gpt-4o-mini once (subject plus a short snippet — never the full body) so it can decide whether it's job-related. That's roughly 300–500 tokens per email, about $0.10 per 1,000 emails at typical gpt-4o-mini rates (check OpenAI's pricing page for the current figure). Each email is classified only once; already-checked emails are skipped on later syncs. Cost scales with how much mail is in the window, so a later Start Date below means a cheaper first sync. Your actual token usage and estimated spend are shown in the Dashboard's Analytics tab.

Sync Start Date

Required — the earliest email the first sync will look at

What this means: your first sync checks inbox mail received on or after this date and ignores everything older. Each later sync only checks mail that arrived since the previous sync finished, so the date matters most for the first run. Every email in that window is sent to OpenAI once, so an earlier date means a longer and costlier first sync — pick roughly when you started applying. Saving a new date restarts the next sync from that date. Sync is disabled until a date is set.
